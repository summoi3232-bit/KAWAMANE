# مسيّر الميزانية الشخصية (PWA)

تطبيق ويب تقدّمي (PWA) لتسيير الميزانية الشخصية: خطة سداد الدين المؤقتة، الخطة الدائمة، تقرير شهري قابل للطباعة كـPDF، أرشيف شهري، ونسخ احتياطي/استعادة.

## محتوى المستودع
```
index.html      → التطبيق نفسه
manifest.json   → بيانات التثبيت (اسم، أيقونات، ألوان)
sw.js           → Service Worker للعمل بدون إنترنت
icons/          → أيقونات التطبيق (192 و512)
```

## النشر من الجوال (GitHub + Netlify)
1. أنشئ مستودعًا جديدًا في GitHub (عبر تطبيق GitHub أو المتصفح) وارفع هذه الملفات الأربعة/المجلد كما هي، دون تعديل المسارات.
2. اربط المستودع بـNetlify (Import from GitHub) — لا حاجة لأمر بناء (Build command فارغ)، ومجلد النشر (Publish directory) هو الجذر `/`.
3. بعد النشر ستحصل على رابط `https://xxxx.netlify.app` — افتحه من متصفح الجوال، وسيظهر خيار "إضافة إلى الشاشة الرئيسية / تثبيت التطبيق" تلقائيًا بفضل ملف manifest.json وsw.js.

## تحويله إلى APK (PWABuilder)
1. افتح [pwabuilder.com](https://www.pwabuilder.com) من متصفح الجوال.
2. ألصق رابط Netlify الخاص بك.
3. تأكد أن الفحص يُظهر Manifest ✅ وService Worker ✅ (لأن الملفين موجودان مسبقًا في المستودع بنفس الأسماء والمسارات النسبية، لا حاجة لتعديل يدوي في مجلد public كما في مشاريع Vite السابقة).
4. اختر Android package → نزّل الـAPK مباشرة.

## ملاحظة تقنية
كل البيانات (الأرقام المدخلة + الأرشيف الشهري) تُحفظ محليًا في `localStorage` على جهاز المستخدم فقط، ولا تُرسل لأي خادم — لذلك لا حاجة لأي قاعدة بيانات أو Backend.
